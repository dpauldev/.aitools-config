# Reusable project subagents

Each `.md` file here is a project-scoped subagent definition worth
reusing across more than one project. Copy one into a project with:

    ./scripts/init_project.sh agents <agent-name>.md

This is a placeholder folder — populate it once an agent built for one
project (like dotfiles-package-auditor or dotfiles-explorer) turns out
to be worth reusing in a second, not speculatively ahead of that.
