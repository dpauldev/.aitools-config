# Reusable project skills

Each subfolder here is one project-scoped skill template
(`<name>/SKILL.md` plus supporting files) worth reusing across more
than one project. Copy one into a project with:

    ./scripts/init_project.sh skills <skill-folder-name>

This is a placeholder folder — populate it once a skill built for one
project turns out to be worth reusing in a second, not speculatively
ahead of that.
